Versão estática do projeto original. As páginas BR e EN foram preservadas e somente o menu inicial foi modernizado.

## Publicação
1. Envie o conteúdo desta pasta para a branch `main` do repositório.
2. GitHub → Settings → Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main`; Folder: `/ (root)`.
5. Save.
